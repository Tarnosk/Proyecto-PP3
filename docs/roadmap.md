# Roadmap

## Estado actual

El proyecto se encuentra en una fase de desarrollo modular con varios dominios del ERP ya estructurados, incluyendo autenticación, clientes, ventas, compras, stock y reportes.

## Objetivos de corto plazo

- consolidar la estructura modular
- revisar permisos y roles por funcionalidad
- definir contratos de integración entre módulos
- mejorar documentación de cada dominio
- reforzar pruebas automatizadas

## Objetivos de mediano plazo

- consolidar la gestión financiera y de stock
- mejorar la trazabilidad de ventas y entregas
- completar reportes y analítica operativa
- revisar consistencia de datos y migraciones

## Objetivos de largo plazo

- incorporar mejoras de performance y observabilidad
- preparar el sistema para entorno productivo estable
- establecer procesos de despliegue y mantenimiento
- documentar manuales operativos para usuarios finales

## Recomendación

Cada nueva funcionalidad debe incorporarse con:

- documentación del cambio
- pruebas mínimas
- revisión del impacto en módulos relacionados
- actualización del roadmap si corresponde
