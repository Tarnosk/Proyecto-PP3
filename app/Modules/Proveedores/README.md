# Módulo Proveedores (Grupo 3)

Este directorio está asignado al **Grupo 3: Proveedores, Plazos de Entrega y Precios de Compra**.

## Estructura estándar
```text
app/Modules/Proveedores/
├── Controllers/         # Controladores de proveedores y plazos
├── Models/              # Modelos (Proveedor, HistorialPrecioProveedor, etc.)
├── Services/            # Lógica de cálculo de plazos de entrega
├── routes/
│   ├── web.php          # Rutas web del módulo
│   └── api.php          # Rutas API del módulo
└── database/
    └── migrations/      # Migraciones específicas del módulo
```
