# Módulo Compras (Grupo 3)

Este directorio está asignado al **Grupo 3: Compras, Órdenes de Compra y Recepción**.

## Estructura estándar
```text
app/Modules/Compras/
├── Controllers/         # Controladores de órdenes de compra y recepción
├── Models/              # Modelos (OrdenCompra, DetalleOrdenCompra, etc.)
├── Services/            # Lógica de reposición y generación de órdenes
├── routes/
│   ├── web.php          # Rutas web del módulo
│   └── api.php          # Rutas API del módulo
└── database/
    └── migrations/      # Migraciones específicas del módulo
```
